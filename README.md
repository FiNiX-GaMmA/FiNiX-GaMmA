## How I approach engineering

- **Local first when it matters.** Keep books, embeddings, voices, credentials, and generated artifacts on the user's machine whenever the product permits it.
- **AI inside explicit boundaries.** Use models for synthesis, retrieval, or direction while deterministic code owns geometry, ordering, persistence, packaging, and recovery.
- **Ship the whole system.** Pair product UX with APIs, tests, CI, security checks, documentation, installers, and versioned releases.
- **Build for the real platform.** Preserve native interaction on Apple, Android/TV, and desktop instead of stretching one interface everywhere.
